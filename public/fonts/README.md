# ASTRA workspace typography

Unmodified Pretendard Variable v1.3.9, distributed with its original SIL Open Font License 1.1 in `Pretendard-OFL.txt`.

- [Upstream project](https://github.com/orioncactus/pretendard)
- [Pinned original WOFF2](https://raw.githubusercontent.com/orioncactus/pretendard/v1.3.9/packages/pretendard/dist/web/variable/woff2/PretendardVariable.woff2)
- [Pinned original license](https://raw.githubusercontent.com/orioncactus/pretendard/v1.3.9/LICENSE)

The CSS family alias `ASTRA Pretendard` confines the font to the workspace; the font binary is unchanged. `font-display: swap` provides a fallback during loading. Numeric and code text use the local monospace fallback stack; no separate numeric-font download is required.
