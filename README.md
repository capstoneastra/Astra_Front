# <img src="public/favicon.svg" width="32" alt="" /> ASTRA 프런트엔드

**우주항공 시험장비 공동활용 플랫폼**

기업·시험기관·대학이 시험장비를 검색하고 비교하며, 시험 의뢰부터 검토와 예약까지 한곳에서 진행하는 웹 애플리케이션입니다.

프런트엔드 개발 **이연지 · 주현욱**

## 기술 스택

| 영역 | 기술 | 활용 |
| --- | --- | --- |
| **화면 및 스타일** | `React 18` · `Tailwind CSS` | 대시보드와 업무 화면 구성, 공통 UI 스타일 적용 |
| **라우팅** | `React Router` | 로그인과 워크스페이스 화면 전환 |
| **API 연동** | `TanStack Query` · `Axios` | 서버 데이터 조회·캐싱과 HTTP 요청 처리 |
| **개발 및 빌드** | `TypeScript` · `Vite` | 타입 검사, 개발 서버 실행과 배포용 번들 생성 |

## 주요 화면

| 화면 | 주요 작업 |
| --- | --- |
| 대시보드 | 소속과 역할에 맞는 업무 현황, 처리할 의뢰, 예정된 시험 일정 확인 |
| 시험장비 검색 | 시험장비와 상세 사양 탐색, 후보 장비 비교, 가상 시뮬레이션 확인 |
| 시험 의뢰·예약 | AI 간편 의뢰(조건 → 장비 → 의뢰서), 의뢰서 제출, 접수한 의뢰 검토와 보완 요청, 예약 일정 확인 |
| AI 어시스턴트 | 상담을 통한 시험 조건 정리, 장비 매칭, 의뢰서 초안 작성 |
| 운영 관리 | 보유 장비 등록·수정, 관리자 계정의 회원·기관 가입 승인 |
| 계정 찾기 | 이름·연락처로 이메일(아이디) 찾기, 이메일 코드 확인 후 비밀번호 재설정 |

## 폴더 구조

```text
.
├── docs/             기능 명세, API 명세, 연동 인수인계 문서
├── public/           파비콘 등 정적 리소스
├── src/
│   ├── api/         공통 HTTP 클라이언트, API 설정과 오류 처리
│   ├── auth/        로그인·회원가입, 세션과 권한 처리
│   ├── components/  업무 화면과 공용 UI 컴포넌트
│   ├── context/     워크스페이스에서 공유하는 상태
│   ├── data/        사이드바 메뉴 정의
│   ├── domain/      일정·시뮬레이션 데이터 가공과 업무 상수
│   ├── hooks/       데이터 조회·요청과 화면 상태 관리 로직
│   ├── services/    업무 기능별 API 호출과 응답 타입
│   ├── styles/      화면별 스타일과 디자인 토큰
│   ├── theme/       테마 전환과 설정 저장
│   ├── App.tsx      인증 화면과 워크스페이스 구성
│   └── main.tsx     React 앱 진입점
├── index.html        Vite HTML 진입점
├── package.json      의존성과 실행 명령
└── vite.config.ts    개발 서버와 번들 설정
```

## 바로 실행하기

```bash
npm i
npm run dev
```

브라우저에서 표시되는 주소(기본 `http://localhost:5173`)로 접속합니다.

백엔드 주소는 `.env.local`에 `VITE_API_BASE_URL=https://<서버 주소>/api/v1` 로 지정합니다(없으면 `/api/v1`).
요청·응답 형식은 [API 명세](docs/api-spec.md)를 그대로 따르며, 화면에 미리 넣어 둔 시연 데이터는 없습니다.
시연용 장비(`isMock`)를 목록에 섞어 볼지는 `VITE_INCLUDE_MOCK_DATA=true` 로 정합니다(운영에서는 false).

> 로그인 화면의 '계정 찾기'(이메일 찾기 · 비밀번호 재설정)는 명세 1-1에 추가한 API를 사용합니다. 서버 구현이 필요합니다.
> 이번 개선 내용은 [UI 개선 기록](docs/ui-improvements-2026-11.md)에 정리했습니다.

## 빌드 및 검사

| 명령 | 용도 |
| --- | --- |
| `npm run build` | 타입 검사 후 배포용 파일을 `dist/`에 생성 |
| `npm run preview` | 빌드된 `dist/`를 로컬에서 확인 |
| `npm run lint` | 소스와 설정을 ESLint로 검사 |

`dist/`는 빌드로 생성되며 Git에서 제외됩니다.
