# ASTRA Frontend

우주항공 시험장비 공동활용 플랫폼의 React, TypeScript, Vite 프런트엔드입니다.

## 개발 서버 실행

Node.js 24를 사용합니다. 의존성을 설치한 뒤 개발 서버를 실행하고 콘솔에 표시된 주소를 엽니다.

```sh
npm i
npm run dev
```

개발 서버는 기본적으로 실제 API를 사용합니다. 기본 경로는 같은 출처의 `/api/v1`입니다. 백엔드를 별도 주소에서 실행하면 `.env.local`의 `VITE_API_BASE_URL`에 백엔드 주소와 `/api/v1` 경로를 설정하세요.

실제 업무는 서버에서 인증한 계정으로 이용합니다. 프런트에서 생성하던 예시 데이터는 제거했습니다. 장비 목록은 기본적으로 서버에 `includeMock=false`를 전달합니다. 서버가 시연용으로 표시한 데이터에는 명세에 따라 `DEMO` 배지가 붙습니다.

개발 서버나 로컬에서 실행한 빌드의 로그인 화면에서는 기업·기관·대학·관리자 버튼으로 각 역할의 화면을 `/`에서 열 수 있습니다. 로컬 화면은 현재 탭에서만 유지되며, 데이터 조회와 업무 요청은 서버로 전송되지 않습니다. 실제 계정은 로그인 폼으로 접속합니다.

업무 기능 및 후속 연동 사항은 [전체 기능 명세](docs/functional-spec.md), [Mock 정리 및 검증 기록](docs/mock-cleanup.md), [백엔드 인수인계](docs/backend-handoff.md)를 참고하세요.

`npm run build`는 타입 검사와 프로덕션 번들을 실행합니다. `npm run preview`는 빌드 결과를 로컬에서 실행합니다. `npm run lint`는 소스와 설정을 검사합니다.
