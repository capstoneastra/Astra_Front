# 업무 화면 예시 데이터

실제 목록이나 결과가 비어 있거나 조회에 실패하면, 항목의 모양을 확인할 수 있는 `화면 예시`를 영역마다 한 건 표시합니다. 기존 로딩, 빈 상태, 오류와 재시도 안내는 각 화면에서 계속 표시합니다. 로딩 중이거나 `401`·`403` 응답을 받으면 예시를 숨깁니다.

## 표시 위치

| 화면 | 예시 영역 |
| --- | --- |
| 대시보드 | 처리할 의뢰, 최근 상담, 검토할 의뢰, 다가오는 예약, 기관별 장비 검증 |
| 장비 탐색 | 검색 결과 카드, AI 매칭 후보, 장비 비교표, 시험 정보, 중복·유사 장비 그룹 |
| 시험 업무 | 시험 의뢰 카드, 캘린더의 다가오는 시험, 업무 알림 |
| 운영 | 보유 장비 관리, 회원 관리, 기관 승인 현황 |
| 가상 시뮬레이션 | 결과 차트, 실행 이력 |

각 예시는 실제 API 응답과 별개의 읽기 전용 화면 요소입니다. 집계, 필터, 장비 선택, 예약 일정, 요청 본문, 다운로드에 사용하지 않습니다. 실제 항목이 표시되는 영역에서는 해당 예시가 자동으로 사라집니다.

## 수정과 제거

1. 문구와 그래프 예시 값은 [`UiExample.tsx`](../src/components/ui/UiExample.tsx)에서 수정합니다. 공통 스타일은 [`ui-examples.css`](../src/styles/ui-examples.css)에 있습니다.
2. `.env.local` 또는 배포 빌드 환경에 `VITE_SHOW_UI_EXAMPLES=false`를 설정하면 모든 예시를 숨길 수 있습니다. 개발 서버를 다시 시작하거나 배포 번들을 새로 빌드해야 반영됩니다. 설정이 없으면 예시를 표시합니다.
3. 코드에서 완전히 제거할 때는 `rg -n 'UiExample' src/components`로 각 화면의 호출과 import를 찾아 삭제한 뒤, `UiExample.tsx`, `ui-examples.css`와 이 문서를 제거합니다.
