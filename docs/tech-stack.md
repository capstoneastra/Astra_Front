# ASTRA 프론트엔드 기술 스택

이 프로젝트의 프론트엔드는 아래 기술 스택을 기반으로 개발합니다. AI는 코드 작성 시 명시된 라이브러리와 프레임워크를 사용합니다.

## 기술 스택 목록

| 구분 | 기술 / 라이브러리 | 역할 및 비고 |
| :--- | :--- | :--- |
| **기본** | React 18 | 함수형 컴포넌트 및 Hooks 기반 UI 구성 |
| **언어** | TypeScript | 정적 타입 정의 및 타입 안정성 확보 |
| **빌드 도구** | Vite | 개발 서버 구동 및 프로덕션 번들링 |
| **라우팅** | React Router | 페이지 이동 및 라우팅 처리 |
| **서버 상태 관리** | TanStack Query | 서버 데이터 페칭, 캐싱 및 비동기 상태 관리 |
| **HTTP 클라이언트** | axios | 백엔드 REST API 통신 |
| **스타일** | Tailwind CSS | 유틸리티 클래스 기반 스타일링 |
