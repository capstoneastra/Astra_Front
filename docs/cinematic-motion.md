# ASTRA — Cinematic Aerospace Workspace

2026-11-23 · 작업 브랜치 `feat/yeonji`

최신 요청에 맞춰 기존의 조용한 궤도 장식을 입체 위성·대기권·별 입자 중심의 우주 장면으로 확장했습니다. 한화 Space Hub의 넓은 우주 영상에서 공간감과 몰입감을 참고했으며, 외부 영상이나 이미지를 복사하지 않고 Three.js, Canvas, CSS로 원본 장면을 제작했습니다.

## 유지한 기능과 구조

- 좌측 사이드바, 상단 헤더, 히어로 검색, 4열 KPI, 하단 2단 그리드를 유지합니다.
- 기존 문구, 검색 제출 및 검색어 전달, 페이지 이동, 역할별 메뉴, AI 패널, 예약·시뮬레이션 기능을 변경하지 않습니다.
- 로그인·회원가입·권한·토큰·API 서비스 및 기존 Mock 제거 정책을 변경하지 않습니다. 장면은 장식이며 장비나 시험 결과 데이터가 아닙니다.
- 인증된 워크스페이스에만 효과를 적용하고 기존 스타일 원본은 보존합니다.
- 배경 모션을 정지하는 별도 버튼은 추가하지 않습니다. 운영체제의 움직임 줄이기 설정을 따릅니다.

## 화면과 모션

| 영역 | 처리 |
|---|---|
| 히어로 | 독자 제작한 입체 위성, 태양전지 패널, 안테나, 절차적으로 생성한 행성 대기권 곡면 |
| 위성 | 부드러운 부유와 회전, 포인터 위치에 반응하는 카메라 시차 |
| 궤도 | 교차하는 3차원 경로와 경로를 따라 움직이는 광점 |
| 조명 | 청색 대기광, 서서히 변화하는 햇빛과 가로 광선, 청록·인디고 성운 |
| 워크스페이스 | 이동·명멸하는 별, 간헐적인 빛 궤적, 천천히 흐르는 오로라 |
| 카드 | 순차 등장, 이동하는 상단 하이라이트, 포인터 조명, 호버 상승, 궤도 장식 회전 |
| 사이드바·AI | 활성 메뉴 인디케이터의 은은한 발광, AI 런처의 조명 변화 |
| 모바일 | 우주 장면 위쪽, 기존 검색 문구·입력 아래쪽으로 배치, 좁은 화면에서 가로 넘침 방지 |

## 디자인 시스템

심우주 배경 `#060913`, 슬레이트 글래스 `rgba(15,23,42,.55)`, blur 16px, 시안·아이스 블루 포인트, 국소적인 인디고 광원을 유지합니다. 본문은 자체 호스팅한 Pretendard이며 수치와 메타데이터는 고정폭 폰트 스택 및 tabular-nums를 사용합니다. 라이트 모드는 기존 밝은 업무 표면과 짙은 우주 히어로를 조합합니다.

기관 위치를 표시하는 지구본·국내 지도, 보라색 블랙홀 장식, 가짜 실시간 관제 수치나 업무용 Mock 데이터를 추가하지 않습니다.

## 성능과 접근성

- 이미 설치된 Three.js를 동적 import하여 장면을 지연 로딩합니다. 새로운 라이브러리·외부 영상·이미지 다운로드를 요구하지 않습니다.
- 위성 장면은 약 30fps, 배경 입자는 약 25fps로 제한하고 기기 픽셀 비율은 최대 1.5로 제한합니다.
- 히어로가 화면 밖으로 나가거나 탭이 숨겨지면 해당 WebGL 루프를 정지합니다. 배경 입자도 탭이 숨겨지면 정지합니다.
- 화면 전환 시 requestAnimationFrame, observer, 이벤트 리스너, WebGL 지오메트리·머티리얼·텍스처·컨텍스트를 해제합니다.
- WebGL을 사용할 수 없거나 컨텍스트가 손실되면 CSS 위성·대기권 장식을 표시하며 업무 UI는 계속 사용할 수 있습니다.
- `prefers-reduced-motion: reduce`이면 두 Canvas를 정지된 장면으로 표시하고 CSS 애니메이션·전환·시차 효과를 정지합니다.
- 모든 장면은 `aria-hidden`, `pointer-events: none`이며 검색 입력과 버튼을 가리지 않습니다. 업무 텍스트 자체에는 반복 이동을 적용하지 않습니다.

## 검증

- TypeScript 및 Vite 빌드 통과. Three.js 공유 청크의 500kB 경고가 있으며 실행 오류는 아닙니다.
- ESLint 통과.
- `node scripts/check-functional-cleanup.mjs` 통과: 기능용 Mock 제거, 계정 데이터 보존, 인증·회원가입 및 기존 스타일 원본 보호.
- Chrome에서 입체 장면 표시, 별 입자의 실제 프레임 변화, 모션 감소 시 입자와 CSS 정지, 기존 문구·4열 KPI·하단 2단 구조·폰트·색상·검색 연결을 확인했습니다.
- 1440px 데스크톱, 390px·320px 모바일, 라이트·다크 모드를 확인했습니다. AI 패널·캘린더·의뢰·시뮬레이션·기관·관리자 화면 이동 및 비회원의 로그인 이동에서 미처리 예외가 없었습니다.
- WebGL 사용 불가와 실행 중 컨텍스트 손실을 각각 재현하여 CSS 대체 장면, 검색 동작, 모바일 가로 넘침 없음을 확인했습니다.
- 실제 백엔드 데이터 및 상태 전이는 **백엔드 미배포로 테스트 불가**입니다. 기존 API 오류를 시연 데이터로 대체하지 않습니다.

이 작업은 로컬 디자인 변경입니다. 공개 배포·PR 생성·병합은 수행하지 않습니다.
